# 度量指标业务呈现模式

用于把飞书项目度量公式转成可快速评审的业务表达。先讲业务逻辑，后给可复制公式；不要把巨型嵌套 `IF` 当作说明。

## 得分指标标准结构

````markdown
## <指标名称>（<满分>）

<1~2句：衡量目标、主要关注点、避免的误读。>

### 计算口径

```text
A = <可读子指标定义>
B = <可读子指标定义>
```

> A/B/C 只是 PlainText 解释别名，不能出现在飞书项目最终公式中。

### 输入说明

<解释参与人、样本、终点、范围、哪些字段不计入。>

### 得分规则

- <守卫条件>，得分为 <x>。
- <主路径或子分组合>。
- <特殊降档/封顶逻辑>。

### 分档

| 子项 | 条件 | 分数 |
| --- | --- | ---: |
| A | ... | ... |
| B | ... | ... |

### 补充说明

| 观察组合 | 业务含义/建议动作 |
| --- | --- |
| A 高且 B 高 | ... |
| A 低且 B 高 | ... |
| A 高且 B 低 | ... |

### 飞书项目可复制公式

```text
<没有变量、没有新增字段、内联完整条件的公式>
```

### 公式自检

- 分数范围：`0~<满分>`
- 样本：...
- 重复逻辑：无 / <需确认>
- 已确认字段：...
````

## 非得分指标简化结构

````markdown
## <指标名称>

<1句业务目的>

### 计算口径

```text
样本 = ...
计算 = ...
边界 = ...
```

### 业务解读

- 高：...
- 低：...
- 无样本：...

### 飞书项目可复制公式

```text
<完整公式>
```
````

## 解析既有公式时

- 从实际公式提取 A/B/C 和守卫条件；不能凭指标名称臆测。
- 同一子表达式反复出现时，只在 PlainText 定义一次，再说明最终公式为内联展开。
- 若发现旧公式与新公式、旧终点与新终点、两段子分重复叠加，单列“逻辑风险”和“最小删除/替换范围”。
- 分档边界必须写成闭开区间，例如 `0.5 ≤ A < 0.8`，不只写“中等”。
