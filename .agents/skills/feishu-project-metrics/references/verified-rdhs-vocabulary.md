# 已确认的飞书项目度量词汇

本文件只保存本项目对话中用户确认或真实 chart 返回过的字段/函数。它是生成公式的**下限白名单**，不是允许补造字段的依据。

## 终点与周期

| 字段 | 已确认用法 |
| --- | --- |
| `${完成时间(秒)}` | 当前统一的完成终点。用户确认：需求侧该聚合字段取值就是验收完成时间。新周期、完成/在途划分应优先使用它。 |
| `${验收完成时间}` | 历史公式字段。新公式若已统一终点为`${完成时间(秒)}`，不得混用；仅用户明确要求保留时才可使用。 |
| `${提出时间}` | 需求交付周期、WIP 年龄的起点。 |
| `${需求就绪时间}` | 当前用户确认可用于“首次进入开发”的起点；此前也描述为“到达可排期”。生成公式时不自行扩展其含义。 |

## 已确认基础字段

| 字段 | 用途 |
| --- | --- |
| `${工作项id}` | 去重计数对象 |
| `${工作项类型}` | `$option{产品需求}` / `$option{缺陷管理}` |
| `${需求状态}` | 需求/缺陷状态过滤 |
| `${需求类型}` | 过滤`预研需求` |
| `${是否需要发布}` | 发布需求过滤 |
| `${严重性}` | `严重` / `致命` 缺陷占比 |
| `${发现深度}` | `容易发现` 等缺陷发现深度 |
| `${参与人员}.${流程角色}` | 角色人员子表 |
| `${角色人员}` | 从流程角色过滤后取参与人 |
| `${所有状态}`、`${状态名称}`、`${状态首次开始时间}` | 历史公式/飞书案例可见；未获用户当前状态名确认前，不得据此造新状态字段或假设状态名。 |
| `$related{[New]产品需求-发布计划关联}` | 发布计划关联；`each.${状态}` 用于发布完成判断 |

## 已确认函数与写法

```text
IF(condition, true_value, false_value)
ISNULL(${字段})
AVGIF(value, condition)
COUNTDISTINCTIF(${工作项id}, condition)
FILTER(${子表}, condition).${字段}
MAX(...)
MIN(...)
AVG(...)
TODAY()
```

条件连接沿用用户已用语法：`&&`、`||`、`OR`。

## 已确认基础口径模式

### 已完成需求数

```text
COUNTDISTINCTIF(
  ${工作项id},
  ${工作项类型} == $option{产品需求}
    && ISNULL(${完成时间(秒)}) == false
)
```

### 有效在途需求数

```text
COUNTDISTINCTIF(
  ${工作项id},
  ${工作项类型} == $option{产品需求}
    && ISNULL(${完成时间(秒)})
)
```

### 已完成需求交付周期

```text
AVGIF(
  (${完成时间(秒)} - ${提出时间}) / 86400,
  ${工作项类型} == $option{产品需求}
    && ISNULL(${完成时间(秒)}) == false
)
```

### 已完成需求开发周期

```text
AVGIF(
  (${完成时间(秒)} - ${需求就绪时间}) / 86400,
  ${工作项类型} == $option{产品需求}
    && ISNULL(${完成时间(秒)}) == false
)
```

### 需求 WIP 时长（平均在途年龄，诊断）

```text
AVGIF(
  IF(
    TODAY() >= ${提出时间},
    (TODAY() - ${提出时间}) / 86400,
    0
  ),
  ${工作项类型} == $option{产品需求}
    && ISNULL(${完成时间(秒)})
)
```

## RDHS 结构约束

```text
RDHS(100')
= 链路闭环得分(25')
+ 交付闭环得分(15')
+ 时效节奏合理性(20')
+ 颗粒度对齐度(20')
+ 质量敏锐度(20')
```

时效新设计的目标范围：

```text
完成节奏子分：0 / 3 / 6 / 9 / 12
在途积压子分：0 / 2 / 4 / 6 / 8
时效节奏：两者之和，0~20
```

注意：在 chart 中遇到列名`完成节奏分`时，先确认它是 0~12 子分还是已经包含 WIP 的 0~20 新时效总分；不要仅按名称推断。

## 不可自动补充的内容

以下必须由用户明确提供后才能进入公式：

- 任意新基础字段；
- 未确认的状态名（如`开发中`、`研发中`、`已取消`、`已作废`）；
- 隐式数据质量限制（提出/就绪非空、时间先后关系等）；
- 新 SLA、WIP 阈值、样本门槛；
- 指标间变量/引用（飞书项目 chart 度量公式不支持变量定义）。
